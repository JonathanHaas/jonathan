Credits

This site is built on open source software and open fonts. Here's what's under the hood.

Software

Eleventy — static site generator. Runs the build, processes Nunjucks templates, and generates the final HTML. MIT license.

Nunjucks — templating language used for layouts, includes, and localization conditionals. Bundled with Eleventy. BSD-2-Clause license.

Wrangler — Cloudflare CLI used for local development and deployment. Apache 2.0 license.

Schemas and standards

JSON Resume — open schema for structured CV data. resume.json follows this spec, which keeps content separate from presentation and makes the data portable.

Typefaces

Jost — display typeface by indestructible type*. Used for headings, navigation, and labels. SIL Open Font License.

Karla — body typeface by Jonny Pinhorn. Used for running text. SIL Open Font License.

Noto Sans SC — Simplified Chinese typeface by Google. Loaded only on the Mandarin pages. SIL Open Font License.
