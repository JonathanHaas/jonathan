Créditos

Este sitio está construido sobre software de código abierto y tipografías abiertas. Esto es lo que hay debajo del capó.

Software

Eleventy — generador de sitios estáticos. Ejecuta la compilación, procesa las plantillas Nunjucks y genera el HTML final. Licencia MIT.

Nunjucks — lenguaje de plantillas usado para layouts, includes y condicionales de localización. Incluido con Eleventy. Licencia BSD-2-Clause.

Wrangler — CLI de Cloudflare para desarrollo local y despliegue. Licencia Apache 2.0.

Esquemas y estándares

JSON Resume — esquema abierto para datos de CV estructurados. resume.json sigue esta especificación, lo que mantiene el contenido separado de la presentación y hace que los datos sean portables.

Tipografías

Jost — tipografía de visualización de indestructible type*. Usada en encabezados, navegación y etiquetas. Licencia SIL Open Font.

Karla — tipografía de texto de Jonny Pinhorn. Usada en el texto corrido. Licencia SIL Open Font.

Noto Sans SC — tipografía china simplificada de Google. Solo se carga en las páginas en mandarín. Licencia SIL Open Font.

Asistencia de IA

Claude (Anthropic) a través de OpenClaw — este sitio fue desarrollado con asistencia de inteligencia artificial. Claude se encargó del código, los textos y las decisiones de diseño; OpenClaw proporcionó la interfaz agéntica y las herramientas.

Inspiración

nownownow.com — la convención de /now creada por Derek Sivers. Una idea sencilla: una página que cuenta en qué estás enfocado ahora mismo.
